# Forum Service v2

Spring Boot 3 application for car discussion forum using Java 17.

## Technology Stack

- Java 17
- Spring Boot 3.2.0
- Spring Web
- Spring Data JPA
- PostgreSQL
- Lombok

## Database Configuration

PostgreSQL database with the following configuration in `application.yml`:

```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/forumdb
    username: postgres
    password: postgres
```

UUID generation is handled by PostgreSQL using `gen_random_uuid()`.

## API Endpoints

### 1. Create Thread
**POST** `/threads`

Request body:
```json
{
  "userId": "user123",
  "type": "car-discussion",
  "modelId": "bmw-m3",
  "title": "BMW M3 Discussion"
}
```

### 2. Create Subthread
**POST** `/threads/{threadId}/subthreads`

Request body:
```json
{
  "userId": "user123",
  "title": "Engine Performance"
}
```

### 3. Create Message
**POST** `/subthreads/{subthreadId}/messages`

Request body:
```json
{
  "userId": "user123",
  "body": "This is a great car!"
}
```

### 4. Vote on Message
**POST** `/messages/{messageId}/vote`

Request body:
```json
{
  "userId": "user123",
  "upvoted": true
}
```

### 5. Get Messages by Subthread
**GET** `/subthreads/{subthreadId}/messages`

Returns all messages for a specific subthread.

### 6. Get All Messages by Model ID
**GET** `/models/{modelId}/messages`

Returns all messages from all subthreads related to a specific car model.

### 7. Get All Threads (Paginated)
**GET** `/threads?page={page}&size={size}`

Returns all threads in the forum with pagination.

Query parameters:
- `page` (optional): Page number (0-indexed, default: 0)
- `size` (optional): Number of threads per page (1-100, default: 10)

Example: `GET /threads?page=0&size=20`

### 8. Get Recent Threads
**GET** `/threads/recent?limit={limit}`

Returns recent threads ordered by creation date (most recent first).

Query parameters:
- `limit` (optional): Number of threads to return (1-100, default: 10)

Example: `GET /threads/recent?limit=5`

## Building and Running

```bash
# Build the project
mvn clean package

# Run the application
mvn spring-boot:run
```

The application will start on port 8080.

## Database Setup

1. Create PostgreSQL database:
```sql
CREATE DATABASE forumdb;
```

2. The application will automatically create tables and insert sample data on startup using `schema.sql`.

## Features

- UUID-based primary keys generated by PostgreSQL
- Composite key implementation for message votes using `@Embeddable` and `@EmbeddedId`
- Transaction management with `@Transactional`
- JPA entity relationships (OneToMany, ManyToOne)
- RESTful API endpoints
- Sample data included for testing
